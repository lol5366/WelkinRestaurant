Приложение для сотрудников ресторана. Выполнен на C#. Логины/пароли: admin|admin123, waiter1|waiter1, waiter2|waiter2
АИС для ресторана

- Создание столов
- Сохранение чеков
- Сохранение отчёта
- Тестирование системы
- Расчёт столов
